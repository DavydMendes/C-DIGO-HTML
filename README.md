# 🌐 Meus Sites Favoritos

Projeto desenvolvido como parte das atividades práticas do curso de Desenvolvimento de Sistemas (ETEC). A página reúne uma seleção de links úteis para estudo e trabalho, organizados em cartões visuais (*cards*).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica da página.
- **CSS3**: Estilização, layout responsivo com *Flexbox*, sombras e efeitos visuais (*hover*).

---

## 📌 Sites Listados

1. **Google** - Motor de busca e ferramentas.
2. **YouTube** - Plataforma de vídeos e tutoriais.
3. **GitHub** - Hospedagem de código-fonte e controle de versão.
4. **Sebrae** - Apoio ao empreendedorismo e capacitação.
5. **Fatec** - Ensino superior tecnológico e oportunidades acadêmicas.
