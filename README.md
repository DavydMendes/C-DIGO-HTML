# 🌐 Meus Sites Favoritos

Projeto desenvolvido como parte das atividades práticas do curso de Desenvolvimento de Sistemas. A página reúne uma seleção de links úteis para estudo, trabalho e entretenimento, organizados em cartões visuais (*cards*).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica da página.
- **CSS3**: Estilização, layout responsivo com *Flexbox*, sombras e efeitos visuais (*hover*).

---

## 📌 Sites Listados

- **Google**: Motor de busca e ferramentas de pesquisa.
- **YouTube**: Plataforma de vídeos e conteúdos educativos.
- **GitHub**: Hospedagem de código-fonte e controle de versão.
- **LinkedIn**: Rede profissional e conexões de carreira.
- **Instagram**: Rede social para acompanhamento de conteúdos e tendências.
